## Bằng chứng đã chạy

`pnpm --filter @goease/api db:check` trên Windows, Node 24.15.0/pnpm 10.34.6/PostgreSQL 18.6: **9 test pass, 0 skip**, gồm 1 suite + 8 subtests, khoảng 10 giây. Không SQLite/in-memory/mock DB. Lỗi startup ban đầu do chuỗi `unix_socket_directories` và inherited daemon pipes đã sửa; không coi các lần lỗi là pass.

| Ca | Kết quả thực |
| --- | --- |
| Fresh DB/role/migration | Hai migration deploy vào cluster/DB trống riêng; runtime grants tối thiểu |
| Seed 2 lần | 3 hàng ổn định, nhãn/nguồn/precision giữ; không seed user/admin |
| CHECK/FK/unique | Giá trị biên ngày/thời gian/nhóm/tiền/coordinate/session/hash/position sai bị DB từ chối |
| Aggregate | Deferred constraint chặn thiếu/trùng/gap/xóa ngày; owner/parent immutable; không ghi dở |
| Privilege | Runtime không DDL/đọc migration table/tự cấp role/disable; insert CUSTOMER qua cột được cấp |
| Receipt/rollback | Unique scope/composite owner FK và lỗi receipt rollback toàn transaction |
| Race thật | Hai pg connection; quan sát `pg_stat_activity.wait_event_type=Lock`; commit stale destructive day set bị chặn |
| Pending upgrade | Core-only đã có dữ liệu, áp dụng invariants, dữ liệu giữ và constraint thực thi |
| Restart/backup/restore | Đóng clients, restart cluster đọc dữ liệu; custom dump/restore DB mới, đọc trip/day/receipt/Place và thử constraint |

Review độc lập rà SQL/schema/least privilege/isolation: không thấy blocker SQL. Finding generated Prisma cycles trong guard và teardown ordering đã được sửa, cần chạy lại toàn bộ checks trên source cuối. Output Prisma vẫn quét ranh giới, chỉ component vòng hoàn toàn trong thư mục generator được phép; fixture chống bypass client/mixed authored cycle được thêm. Source SHA/root checks/CLI local/drift/CI cuối sẽ bổ sung sau khi chạy, không suy từ test cũ.
