## Phạm vi và phép kiểm

Challenge one-time nonce/proof 5 phút; Google SDK ID-token verification; opaque hashed Session 24 giờ tách web/native; cookie prelogin/HttpOnly Secure/Origin/CSRF; current role/disabled mỗi request; server-only admin. Migration3 giữ hàng Session cũ nhưng revoke provenance chưa biết. DB runtime không ghi role/disabled/tokenHash/transport/CSRF hash sau cấp; User upsert chỉ cột được cấp.

Đã chạy vòng nhẹ trên Windows/Node 24.15.0/pnpm 10.34.6: contracts build, Prisma generate, TypeScript API noEmit và ESLint các file API sửa **pass**. Các test mới dưới đây đang chờ lượt chạy nặng; chưa ghi pass khi chưa có output thực.

| Bộ ca bắt buộc | Loại chứng cứ / trạng thái |
| --- | --- |
| Google RS256 success/tamper/kid/issuer/audience/expiry/iat/nonce/subject/alg, control/name codepoint | Test fixture RSA tạo trong RAM, SDK thực offline; chờ chạy |
| Cert failure timeout/no retry, safe error/config missing | Transport test-only observation; không gọi Google; chờ chạy |
