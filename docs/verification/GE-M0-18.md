## Sửa race của dev regression sau CI đầu PR #19

[Quality Gate run 38121275917](https://github.com/nyanduong/go-ease-webapp/actions/runs/38121275917) trên `26ee1ce0fc1c88ab04b0cd63f77a8f542a92eb11` **thất bại** ở test dev Ubuntu; kiến trúc/API/UI/smoke đã đạt. Log có hai lượt Node watcher restart: probe API nhận phiên bản contracts mới sau lượt đầu, nhưng request browser trúng downtime lượt sau. UI báo lỗi kết nối đúng; assertion một lần của test chờ lỗi contract nên thất bại.

Source sửa test: `ad2f2d9381c7f85ee3aa35979360364d195b5919`. Test dùng nút retry thật có giới hạn để chờ đúng nội dung UI lúc khởi động, cập nhật guard và phục hồi. Regression giữ API fixture ở trạng thái chưa listen bằng gate file, kích hoạt restart thật sau readiness probe, xác minh `requestfailed` và đúng thông báo mạng, rồi mở gate và xác minh đúng lỗi guard. Gate chỉ trong fixture tạm, có deadline và giải phóng ở `finally`; không mock fetch hoặc thay code sản phẩm. Các assertion TS2322, dist không đổi khi compile lỗi, runtime phục hồi, byte-exact source và dừng process/cổng đều giữ.

Đã tái hiện âm bằng phiên bản assertion một lần trong fixture có gate: exit 1 đúng tại `toBeVisible()` của thông báo malformed health; file thí nghiệm đã bỏ. Sau sửa, Windows `pnpm typecheck`, `pnpm lint`, `pnpm test` (46 ca), `pnpm build` đều đạt; dev regression riêng cũng đạt. Reviewer nội bộ đọc lại diff và xác nhận đã xử lý race; **kết quả Ubuntu cuối phải lấy từ Quality Gate trên HEAD PR mới**, không lấy local thay CI.
