# GE-M0-27 — UTC và giới hạn client PostgreSQL

Issue [#27](https://github.com/nyanduong/go-ease-webapp/issues/27), branch `nyan/issue-27-db-bounds`, base main `683a6c3`, ngày 11/10/2026. Điều phối tách sửa client dùng chung từ kết quả PostgreSQL thật ở #4 để #4/#7/#5 kế thừa một fix đã merge. Không đổi schema/migration hoặc timezone DB/role/hệ thống.

Lỗi gốc: với session Asia/Bangkok, adapter-pg 7.10 serialize UTC digits không offset và normalize offset trả về thành +00; instant có thể lệch 7 giờ. Client ép UTC mỗi kết nối, giữ options khác và cưỡng chế pool5/connect-acquire3s/statement-query5s/idle10s. Không log URL/bind/error driver.

## Kiểm chứng đang thực hiện

Windows, Node 24.15.0, pnpm 10.34.6, PostgreSQL binaries local; cluster/roles mới dưới thư mục fixture random loopback, không dùng DB/service hiện có. Frozen install offline đã thành công, 880 package reused/0 download, không đổi lockfile. Source test/commit và kết quả từng lệnh được ghi sau khi chạy thật.
