- `logo.png`: original circular GoEase logo supplied by the project owner, reused from `C:/Wed-GoEase/goease-site/dist/assets/goease-logo.png`. The app displays it with circular clipping; the original is preserved.

The original slogan remains **Just go. We’ll plan.** The interface is Vietnamese by default. These assets are local so the home page does not depend on a remote image service.
